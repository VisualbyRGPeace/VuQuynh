# Thiệp cưới online — Vũ Nguyễn & Như Quỳnh Trang web tĩnh 1 file (`index.html`), không cần cài đặt gì, chạy được ngay trên GitHub Pages. ## Cách đăng lên GitHub Pages 1. Vào [github.com](https://github.com), tạo repository mới, ví dụ đặt tên `wedding` (để **Public**). 2. Vào repo vừa tạo → **Add file → Upload files** → kéo thả file `index.html` vào (đổi tên thành đúng `index.html`, viết thường). 3. Bấm **Commit changes**. 4. Vào tab **Settings → Pages** (menu bên trái). 5. Ở mục **Build and deployment → Source**, chọn **Deploy from a branch**. 6. Ở mục **Branch**, chọn `main` và thư mục `/ (root)` → **Save**. 7. Đợi 1–2 phút, GitHub sẽ hiện link dạng: `https://.github.io/wedding/` Đó chính là link thiệp cưới online của bạn, gửi được cho khách. ## Những chỗ cần cập nhật sau (đang để placeholder) Mở `index.html` bằng bất kỳ trình soạn thảo text nào (Notepad, VS Code...) và tìm các chữ `[Placeholder]` hoặc comment `CẬP NHẬT SAU`: - **Ảnh cặp đôi**: hiện đang là các khung kẻ sọc "Ảnh của bạn tại đây" (phần Love Story). Thay bằng thẻ `` khi có ảnh, hoặc nhắn mình để mình chèn giúp. - **Địa điểm tiệc mừng (Reception)**: đang để trống, điền địa chỉ vào phần "Details". - **Lịch trình (Itinerary)**: giờ đón khách / làm lễ / tiệc mừng đang là giờ mẫu, sửa lại cho đúng. - **Câu chuyện tình yêu**: 3 đoạn trong phần "Love Story" đang là văn mẫu, thay bằng câu chuyện thật của hai bạn. - **Trang phục (Dresscode)**: chưa có yêu cầu cụ thể, có thể xoá phần này hoặc điền thông tin. - **Hạn RSVP**: đang để `__ / __ / 2027`, điền ngày cụ thể. ## Kích hoạt form RSVP (để nhận được phản hồi của khách) Vì đây là trang tĩnh (không có máy chủ riêng), form RSVP cần một dịch vụ trung gian miễn phí để gửi kết quả về email bạn.
